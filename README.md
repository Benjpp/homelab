## 🛠️ Infraestructura y despliegue (Self-Hosted)

El proyecto está desplegado en un entorno de homelab propio, priorizando la seguridad y la autonomía de la infraestructura.

### Stack de Servidor
- **Caddy Server**: Gestiona la terminación SSL (HTTPS) y actúa como Reverse Proxy hacia la aplicación.
- **DuckDNS**: Implementación de DNS dinámico para la resolución del dominio.
- **Apache**: Servidor de aplicaciones interno para el procesamiento de Laravel.

### Capas de Seguridad
- **Fail2Ban**: Protección activa del acceso SSH mediante el bloqueo automático de IPs sospechosas (Anti-bruteforce).
- **SSL/TLS**: Cifrado de extremo a extremo gestionado automáticamente por Caddy.
